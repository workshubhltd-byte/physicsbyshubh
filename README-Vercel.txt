PhysicsByShubh — Vercel aur Google Search Console

Is folder mein aapki site, Class 7 Heat MCQs, aur Google verification file hai.

1. Is ZIP ko unzip karein.
2. Apne Vercel project se connected Git repository mein is folder ke andar ki website files (folder ke andar files, outer folder nahi) update karein. Verification file google4403f91eda7da94f.html ko index.html ke saath site root mein rakhein. Agar aapka project public folder se static files serve karta hai, toh use public folder mein rakhein.
3. Changes commit/push karke Vercel deploy hone dein. Apne current project mein deploy karein, naya project banane ki zaroorat nahi.
4. Browser mein https://physicsbyshubh.vercel.app/google4403f91eda7da94f.html kholkar check karein ki google-site-verification wali line dikhti hai.
5. Google Search Console ki Verify button dabayein. Verification ke baad bhi file na hatayein.
6. Search Console > Sitemaps mein sitemap.xml submit karein.

Yeh local package hai, aapki live site automatically update nahi hui hai.
Vercel par Netlify Forms nahi chalte: purana Ask a Doubt form submissions ke liye alag form backend ki zaroorat hogi.
